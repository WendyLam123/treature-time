## Description
Treasure Time is a website that helps Drexel student to choose their dining and housing plans. It includes 5 main sections: the main page, the page that includes the main on-campus dining information, the page that includes the main on-campus housing information, the calculator page where users can get recommendations, and a survey page where user can submit their opinion. 

The main page: 
The main page includes a brief introduction of our website and buttons that link to the different sections. 

The dining page:
There is a main dining page that includes all the main information about dining locations and Drexel’s dining plans. The dining locations cards are clickable and can navigate the user to separate dining locations pages that include more specific details, such as an embedded map and menu. 

The housing page:
The main housing page includes all the main information about housing locations and plans. In the Detailed Dormitory Guide, the housing location can guide users to more detailed individual pages. 

The calculator page:
The calculator page allows users to input their preferences, such as their term budget and their eating habits. After receiving user preferences, the system calculates the best combination of dining and housing options and other combination options for the user to choose. It also shows the reason for the recommendation, why these fit the user, and the breakdown of the cost of the combination.

The survey page: 
The survey page allows users to submit their feedback about Drexel dining, housing, our website, and other areas. Submitted feedback is stored in the feedback_form.txt.
